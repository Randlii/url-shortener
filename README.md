# Сервис сокращения ссылок

Консольное приложение на Java 17, которое превращает длинный URL в короткую ссылку
(`clck.ru/AbC123`), считает переходы, блокирует ссылку по достижении лимита и удаляет её
по истечении времени жизни. Пользователь идентифицируется по UUID без авторизации.

## Возможности

- Короткая ссылка для любого http/https URL. Код случайный (Base62, 6 символов), поэтому
  один и тот же URL у разных пользователей даёт разные короткие ссылки.
- У пользователя может быть сколько угодно ссылок, пользователей тоже сколько угодно.
- Лимит переходов задаёт пользователь (или берётся значение по умолчанию из конфигурации).
  Когда лимит исчерпан, переход блокируется, а владелец получает уведомление.
- Время жизни задаётся системой в конфигурации (по умолчанию 24 часа). Протухшие ссылки
  удаляет фоновая задача, а также проверка при каждом обращении.
- UUID создаётся при первой команде `create`. Менять лимит и удалять ссылку может только владелец.
- Переход по ссылке открывает исходный URL в браузере через `Desktop.browse`.
- Уведомления выводятся в консоль перед следующим приглашением `>`.

## Требования

- JDK 17+
- Maven 3.8+

## Сборка и запуск

```bash
mvn clean package
java -jar target/url-shortener-1.0.0.jar
# или со своим файлом конфигурации
java -jar target/url-shortener-1.0.0.jar /path/to/application.properties
```

## Конфигурация

Файл `src/main/resources/application.properties` (можно передать свой путём в аргументе):

| Параметр | По умолчанию | Описание |
|---|---|---|
| `shortener.base-url` | `clck.ru/` | префикс короткой ссылки |
| `shortener.code-length` | `6` | длина кода |
| `shortener.ttl-hours` | `24` | время жизни ссылки, часы |
| `shortener.default-max-clicks` | `10` | лимит переходов, если пользователь его не указал |
| `shortener.max-allowed-clicks` | `1000` | максимальный лимит, который можно задать |
| `shortener.cleanup-interval-seconds` | `60` | период фоновой очистки |

## Команды

| Команда | Что делает |
|---|---|
| `create <url> [лимит]` | создать короткую ссылку |
| `open <ссылка>` или просто `<ссылка>` | перейти по ссылке |
| `list` | мои ссылки: переходы, срок действия |
| `info <ссылка>` | параметры ссылки |
| `limit <ссылка> <число>` | изменить лимит (только владелец) |
| `delete <ссылка>` | удалить ссылку (только владелец) |
| `whoami` | показать свой UUID |
| `login <uuid>` | продолжить работу под ранее выданным UUID |
| `logout` | сбросить текущего пользователя |
| `help`, `exit` | справка, выход |

Пример сессии:

```

Лимит переходов: 2, действует до 10.11.2026 20:08:25
> clck.ru/VcWXRT
Переход на https://www.baeldung.com/java-9-http-client (осталось переходов: 1)
> clck.ru/VcWXRT
Переход на https://www.baeldung.com/java-9-http-client (осталось переходов: 0)
[Уведомление] Лимит переходов по ссылке clck.ru/VcWXRT исчерпан (2). Ссылка больше недоступна, создайте новую.

Лимит переходов исчерпан, ссылка недоступна. Создайте новую ссылку.
```

## Архитектура

```
ru.mifi.shortener
├── Main                    сборка зависимостей и запуск
├── config/AppConfig        чтение и проверка параметров из .properties
├── domain/                 ShortLink, LinkStatus, VisitResult
├── repository/             LinkRepository + InMemoryLinkRepository (ConcurrentHashMap)
├── service/                LinkService (бизнес-логика), RandomCodeGenerator, UrlValidator,
│                           NotificationService, ExpiredLinkCleaner, исключения
└── cli/                    ConsoleApp (цикл команд), BrowserOpener, DesktopBrowserOpener
```

Решения:

- Слои разделены: CLI знает только про `LinkService`, сервис работает с интерфейсом
  `LinkRepository`, зависимости передаются через конструктор (легко подменить в тестах).
- Время берётся из `java.time.Clock`, поэтому TTL проверяется в тестах без ожидания.
- Подсчёт переходов атомарный (`synchronized` на ссылке), лимит не обходится
  параллельными запросами.
- Уникальность кода гарантирует `putIfAbsent` в хранилище; при коллизии код генерируется заново.

## Тестирование

```bash
mvn test
```

26 тестов (JUnit 5):

- `LinkServiceTest` — уникальность ссылок для разных пользователей, коллизии кодов,
  лимит и блокировка, TTL и автоудаление, права владельца, валидация URL и лимитов,
  параллельные переходы.
- `ConsoleAppTest` — интеграционные сценарии через консоль: создание и переход,
  исчерпание лимита, уведомление об истечении срока, запрет удаления чужой ссылки,
  обработка ошибочного ввода.
- `AppConfigTest` — загрузка конфигурации и проверка некорректных значений.
